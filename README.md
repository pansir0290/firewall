# 🚀 智能防火墙交互管理工具 (Smart Firewall Manager)

这是一个基于 Bash 编写的智能、轻量级 Linux 防火墙交互式管理脚本。它完美兼容传统的 `iptables` 和新一代的 `nftables`，采用**严格的白名单机制**（默认拒绝所有入站流量），并通过人性化的菜单让你自由地放行或封锁端口。

---

## ✨ 核心特性

* 🤖 **双引擎智能兼容**：自动检测系统底层防火墙，无缝切换 `nftables` 或 `iptables`。
* 🔒 **严格白名单机制**：默认拒绝一切外部入站请求，最大化保障服务器免受恶意扫描。
* 🔍 **首次运行智能防失联**：自动探测系统当前正在监听的端口并一键放通。
* 🎛️ **高级端口放行**：支持单个端口（如 `80`）或端口范围（如 `8000-9000`）。
* ⚡ **一键全开/紧急恢复**：提供一键放通所有端口模式。

---

## 🛠️ 一键远程运行命令

```
curl -sSO https://raw.githubusercontent.com/pansir0290/firewall/main/fw.sh && bash fw.sh
```

📖 交互菜单说明
=== 智能防火墙高级管理菜单 (nftables/iptables) ===
1. 开启白名单模式 (默认拒绝一切 + 自动放行当前服务端口)
2. 查看当前放行规则
3. 手动放行端口/端口范围 (支持 TCP/UDP/ALL)
4. 封锁/删除指定规则
5. 一键放通所有端口 (切换为全开模式)
6. 手动保存当前规则
7. 退出脚本
